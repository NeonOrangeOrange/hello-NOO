## Have an `__init__.py` file

The `__init__.py` file defines what the import does.




## Have a `__main__.py` file

This is a file that can be executed when you call the package as a module

From the terminal, if you run

```bash
python3 -m my_python_package
```

it will run the `__main__.py` file from the package `my_python_package`
